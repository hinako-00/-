**成果物：** [`mbti-ai-compatibility.html`](./mbti-ai-compatibility.html)（単一HTMLファイル。外部依存なし／ライト・ダークテーマ対応）

## この資料の位置づけ

「MBTIで人を分類する資料」ではなく、**人間の個人差を理解し、それぞれに合ったAI活用を設計する資料**。

結論は一貫して次の一点に置いている。

> AIの性能を最大化するのではなく、人間とAIの「相性」を最大化する。

## 編集方針

1. **事実と仮説を混ぜない。** すべての記述に `研究` / `仮説` / `限界` / `実務` のラベルを付与している。第4〜6章および第8章の事例は実証研究ではなく実務上の作業仮説。
2. **MBTIについて肯定面だけを書かない。** 再検査信頼性の議論、予測妥当性への批判、二分法の問題、16Personalitiesとの違い、誤用の危険性を必ず含める。
3. **決めつけを排除する。** 「○○タイプは必ずこうする」「タイプによって能力が決まる」という表現は使用しない。
4. **研究間の不一致を隠さない。** 性格特性とAI信頼の関係は方向すら研究間で一致していないため、その旨を明記している。
